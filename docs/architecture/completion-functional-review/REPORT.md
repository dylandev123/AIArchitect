## Instructions versus execution

The retained system instructions already say to reserve runs, headroom, landings and slab voids before enclosure, check door clearances, and complete pool bottom/perimeter/coping/dry access. Therefore the stair failure is chiefly failure to follow and geometrically verify existing instructions, not simply insufficient wording. The provider's statement that it modeled a route is not evidence of usable headroom.

One important restriction in the paid runner required every pre-existing `pool-*` element to remain byte-equivalent. Adding the missing north wall complied with that restriction; changing the basin depth or existing raised walls would not. A future completion request needs an explicit, bounded decision about which pool elements may change. Repeating “complete the pool” while forbidding their adjustment is unlikely to solve it.

The broad loggia opening also needs an explicit open-air versus enclosed decision. Another generic instruction to “fix the misaligned door” would target the wrong defect and could make the sill placement worse.

## Focused verification changes

Added `focusedConstruction.ts`, integrated into the existing architectural review. It checks named stair tread/landing overlap, connected tread-group endpoints near floor/landing surfaces, centreline obstruction within a 2 m review envelope, actual upper opening/shared-edge intersection, raised upper sills, pool depth and sampled wall-to-bottom continuity. The 2 m envelope is a diagnostic threshold, not a jurisdictional code claim. Checks do not reject transactions or approve scenes. Small pools can remain intentional reflecting features; pool depth is a review finding. Other lifts, ramps, separate wings, rotated geometry and different stair designs are not declared invalid merely because they do not fit this evidence model.

Fixed the pool-seeded residential contact graph. Fixed door alignment to allow a smaller sill-aligned door within a larger opening, while preserving opening-fit checks and detecting genuinely raised/misaligned entrance sills. The upper passage check uses the overlap with the whole shared edge, not a potentially misleading edge midpoint.

Limits: centreline samples can miss edge obstructions; endpoint contact is necessary evidence only; pitched roofs and specialist geometry require mesh review. Pool perimeter sampling cannot establish watertightness or structural adequacy. The new checks distinguish these limits from approval. General requested-space warnings remain because the supplied plan is narrative rather than a detailed allocated plan.
